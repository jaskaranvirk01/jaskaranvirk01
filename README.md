# 💫 About Me:
I'm an AI/ML Software Engineer specializing in Generative AI and LLM applications, with a strong full-stack development foundation. My work centers on building production-oriented systems that turn machine learning concepts into reliable, real-world tools — from retrieval-augmented generation (RAG) pipelines to cloud-native backends and LLM-integrated applications.<br><br>My flagship project, AskDOCS, is a RAG-based document Q&A system built with FastAPI, PostgreSQL (pgvector), Gemini embeddings, and the Mistral LLM. Through a 6-stage retrieval pipeline using 3072-dimensional Gemini embeddings and semantic search, the system significantly reduces irrelevant and hallucinated answers, while a modular service/repository architecture with Supabase Storage ensures secure, authenticated access across a multi-user, production-ready backend.<br><br>Beyond generative AI, I've built SnapClass, an AI-powered smart attendance system that replaces manual roll-call with a dlib-embeddings and SVM facial-recognition pipeline, achieving 98% recognition accuracy and cutting attendance-taking effort by roughly 95%. My other projects include Resumind, an AI-driven resume analyzer that improved feedback accuracy by 40% through an intelligent suggestion engine, and Splitr, a real-time expense management app built on Next.js and Convex that improved app responsiveness by 40% and reduced manual reconciliation effort by 80%.<br><br>My technical toolkit spans machine learning and GenAI frameworks — including LangChain, LangGraph, PyTorch, scikit-learn, Ollama, and ChromaDB — alongside strong data analysis skills in NumPy, Pandas, Seaborn, and Matplotlib. On the engineering side, I work fluently across Python, JavaScript/TypeScript, and Java, with hands-on experience in React.js, Next.js, FastAPI, Node.js, and databases like PostgreSQL, MongoDB, and Supabase.<br><br>I'm currently pursuing a Bachelor of Computer Applications at Chandigarh University (CGPA: 8.62, expected 2027) and have strengthened my engineering fundamentals through certifications in AI/ML Engineering, Full-Stack Web Development, and Data Structures & Algorithms from Apna College, along with solving 140+ algorithmic problems on LeetCode. I'm actively seeking opportunities as a Generative AI or Machine Learning Engineer, where I can continue building AI systems that move beyond prototypes into dependable, production-grade products.
